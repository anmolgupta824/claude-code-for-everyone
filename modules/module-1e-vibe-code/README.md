**Build and deploy a real website. Zero coding experience required.**

## ~1.5 hours | 6 hands-on lessons | FREE

## What You'll Build

A personal website — portfolio, about-me page, or landing page for anything you want to promote. By the end of this module, you'll have a live URL you can share with anyone.

```
yourname.vercel.app   ← your actual live website
```

You won't write code. Claude Code does that. You're the director — you tell Claude what you want, review it, and iterate until it looks right.

## FAQ

**Q: Do I need to know HTML or CSS?**
A: No. Claude generates all the code. You review it, describe what you want to change, and Claude edits it. You're the director, not the coder.

**Q: What if I mess something up?**
A: Claude can fix anything. Just describe what went wrong and it'll sort it out.

**Q: Can I use a custom domain instead of .vercel.app?**
A: Yes — there's a bonus step in Lesson 6 for connecting a custom domain if you have one.

**Q: What does "deploy" mean?**
A: It means putting your site on a server so anyone in the world can visit it through a URL. Vercel handles all the technical parts — you just run a command and it's live.

**Q: How long does deployment take?**
A: About 2 minutes once you have the Vercel CLI set up.

**Q: Can I keep editing after it's deployed?**
A: Yes. Any time you make a change and re-deploy, the live site updates automatically.
