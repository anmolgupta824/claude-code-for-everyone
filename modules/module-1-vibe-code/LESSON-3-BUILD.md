# Lesson 3: Build

**Time:** 20 minutes | **You'll do:** Claude generates your website, you review it

---

## What Happens in This Lesson

Claude reads your design brief and builds the first version of your website. You'll review it in your browser. Then you'll give feedback and Claude will revise.

By the end of this lesson, you'll have a working website file you can open in any browser.

---

## Step 1: Tell Claude to Build

In this Claude Code session, say:

```
Read my design-brief.md and build my website.

Create two files:
- index.html (the website structure and content)
- style.css (the visual design — colors, fonts, layout)

Build the full site based on my brief. Use clean, modern HTML and CSS. No frameworks — just plain HTML and CSS. Make it look good on both desktop and mobile.
```

Claude will read your brief and generate the files. This takes 1-2 minutes.

---

## Step 2: Open Your Site in a Browser

Once Claude writes the files, open your website:

**On Mac:**
```bash
open index.html
```

**On Windows:**
```
start index.html
```

**Or:** Open your file manager, navigate to `~/my-website/`, and double-click `index.html`.

Your website will open in your default browser. This is YOUR site, running on your computer.

---

## Step 3: Review It

Look at your site with fresh eyes. Ask yourself:

**Does it feel right?**
- Does the overall vibe match what you described?
- Are all your sections there?
- Does the color scheme feel right?

**Is the content accurate?**
- Is your name spelled correctly?
- Is your bio what you wanted?
- Are the section headings right?

**What needs changing?**
Make a mental note (or write it down) of 3-5 things you want to change. You'll do this in Lesson 4.

---

## Step 4: Give Initial Feedback

Tell Claude what you think. Be specific:

**Good feedback:**
- "The header looks great but the About section text is too small"
- "Change the background color from light gray to white"
- "The bio in the About section should say [your actual words] instead of what's there"
- "Add a line break between the hero and the About section"

**Not helpful:**
- "I don't like it" (too vague — Claude can't fix vague)
- "Make it better" (better how?)

Work through 1-2 changes now. Save the bigger redesign work for Lesson 4.

---

## Quick Reference

```
Build command:    Tell Claude to read design-brief.md and build
Output files:     index.html + style.css in ~/my-website/
Preview:          open index.html (Mac) / start index.html (Windows)
Feedback rule:    Be specific. "Header font too large" not "looks off"
```
