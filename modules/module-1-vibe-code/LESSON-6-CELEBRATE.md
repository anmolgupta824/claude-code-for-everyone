## Keep Building

Your website is live, but it's not finished. Nothing ever is.

Here are things you can add whenever you want:

- **More projects** — Add them as you finish them
- **A blog** — Write one post, see how it feels
- **Analytics** — Add Vercel Analytics (free) to see how many people visit
- **Dark mode** — Ask Claude to add a dark mode toggle
- **Animations** — Ask Claude to add scroll animations
- **A custom domain** — yourname.com connected to Vercel

Every improvement is one conversation with Claude. Open your `~/my-website` folder, start a session, and say what you want changed.
