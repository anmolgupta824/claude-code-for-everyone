## How to Use This Module

### Option 1: Clone from GitHub

```bash
git clone https://github.com/anmolgupta824/claude-code-for-everyone.git
cd claude-code-for-everyone/modules/module-0b-everyone
claude
```

Then type `start` and follow the teacher's instructions.

### Option 2: Ask Claude to Clone (in Claude Code)

Open Claude Code and type:

```
Clone module-0b-everyone from https://github.com/anmolgupta824/claude-code-for-everyone
Then tell me how to start the lessons
```

Claude will fetch the module and explain the setup.

### Option 3: Download Manually

1. Visit: https://github.com/anmolgupta824/claude-code-for-everyone
2. Click "Code" → "Download ZIP"
3. Extract, open the `modules/module-0b-everyone` folder in Claude Code
4. Type `start`

## Teaching Method

This module uses a **teacher brain** (CLAUDE.md) to deliver lessons interactively.

When you open the folder in Claude Code and say "start":
- Lessons are delivered section-by-section (not all at once)
- Each section has interactive exercises you do RIGHT NOW
- Claude guides you through, checks your work, answers questions
- Everything stays in one session (no "open a new terminal" nonsense)
- You build real files and skills you'll actually use

## FAQ

**Q: Can I skip lessons?**
A: Not recommended. Each lesson builds on the previous one. But Lessons 5+ are somewhat independent — you can jump to Lesson 5 (Skills) if you want to focus there.

**Q: Do I need Claude Pro?**
A: Yes. You need Claude Pro or Max for full Claude Code access. Free tier won't work for this course.

**Q: How long does it actually take?**
A: 2-3 hours if you work straight through. Most people spread it over 2-3 sessions (30-45 min each).

**Q: Can I save my progress?**
A: Yes. Each lesson completion is tracked in `progress.json`. When you close and reopen the module, you'll pick up where you left off.

**Q: I have no coding experience. Is this too advanced?**
A: No. This course was built for non-coders. The "code" you'll write is mostly configuration files and text prompts — not programming. If you can write an email, you can do this.

**Q: What if I mess up a lesson?**
A: No problem. Just delete the file or folder and start the lesson again. The teacher will guide you through.
